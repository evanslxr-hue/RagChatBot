# 5-Minute Demo Script

1. **Login/Register (30s)**
   - Show registration, then login.

2. **Create Course (30s)**
   - Create "Data Structures" course.

3. **Upload PDFs (60s)**
   - Upload 1-2 PDFs (lecture notes).
   - Show PDF list and ingestion status.

4. **Run Ingestion (60s)**
   - Trigger `/ingest`.
   - Show success message and status update.

5. **Ask Questions (90s)**
   - Ask a question about the selected course.
   - Show answer with citations.

6. **All Courses Query (30s)**
   - Toggle "Search across all courses" and ask another question.

7. **Wrap Up (10s)**
   - Mention local LLM, Chroma persistence, and citations.
